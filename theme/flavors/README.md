# Flavors

Ready-made colour versions of Tahoe. Each file is a complete `Tahoe.theme.css`: the same import of
the published theme, with a settings block set to that palette. All are dark except Tahoe Light,
which recolours Discord's dark mode, so keep Discord itself set to dark.

| Flavor | File | Accent | Tint |
|---|---|---|---|
| Catppuccin Mocha | `Tahoe-Catppuccin-Mocha.theme.css` | Mauve `#cba6f7` | Mantle `#181825` |
| Catppuccin Macchiato | `Tahoe-Catppuccin-Macchiato.theme.css` | Mauve `#c6a0f6` | Mantle `#1e2030` |
| Nord | `Tahoe-Nord.theme.css` | Frost `#5e81ac`, text `#88c0d0` | Polar Night `#2e3440` |
| Tokyo Night | `Tahoe-Tokyo-Night.theme.css` | Blue `#7aa2f7` | bg_dark `#16161e` |
| Rosé Pine | `Tahoe-Rose-Pine.theme.css` | Iris `#c4a7e7` | Base `#191724` |
| Everforest | `Tahoe-Everforest.theme.css` | Green `#a7c080` | bg_dim `#232a2e` |
| Gruvbox Dark | `Tahoe-Gruvbox-Dark.theme.css` | Orange `#fe8019` | bg0_h `#1d2021` |
| Graphite | `Tahoe-Graphite.theme.css` | Graphite `#8c8c8c` | neutral `#121214` |
| Midnight | `Tahoe-Midnight.theme.css` | System blue `#0a84ff` | black, near-opaque |
| Light | `Tahoe-Light.theme.css` | System blue `#007aff`, text `#0050b0` | light grey `#f2f2f6`, dense |

To install, put the file in the Vencord themes folder (**Vencord > Themes > Open Themes Folder**)
and enable it in place of `Tahoe`, or replace your `Tahoe.theme.css` with it. Enable only one
Tahoe file at a time.
